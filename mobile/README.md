# CaddieInsight mobile (Expo SDK 57)

Native iOS/Android coaching client. Node `>=22.13 <23` (see `.nvmrc`).

```bash
npm start
npm test -- --runInBand
npm run typecheck
npm run lint
```

App routes live under `src/app/` (Expo Router). Public config is `src/config/env.ts`. See the implementation plan and `docs/CURSOR_MOBILE_APP_HANDOFF.md`.
