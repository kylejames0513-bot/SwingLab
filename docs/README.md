# CaddieInsight documentation

This index covers every document in `docs/`. A doc that is not listed here is
either new (add it) or should not exist. **Read the freshness markers**: this
repo learned the hard way that a stale doc presenting itself as current state
costs real work — a same-day-stale audit misled a full planning pass on
2026-08-10. When a doc and the code disagree, the code is right; when a doc
and the live store disagree, the store is right.
